# Elevate Profile Studio

Premium digital identity website for a Kenyan personal branding and portfolio design studio.

## Stack

- Next.js 15 (App Router)
- Tailwind CSS v4
- Framer Motion
- TypeScript

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
